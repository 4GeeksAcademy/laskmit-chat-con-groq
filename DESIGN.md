# Core Syntax Design System

## Vision
A clean, high-contrast professional theme designed for developer tools and technical interfaces. It prioritizes readability and structural clarity using a crisp slate-based palette.

## Color Palette
The system uses a neutral slate scale for surfaces to reduce eye strain, with a vibrant 'Core Blue' (#2563eb) for primary actions and highlights.

## Typography
Uses the **Geist** typeface, optimized for clarity in both UI labels and technical content like code blocks.

## Components
- **Navigation:** Integrated sidebars with subtle border separation.
- **Cards:** Flat design with `outline-variant` borders rather than heavy shadows.
- **Inputs:** High-contrast fields with clear focus states using the primary brand color.
